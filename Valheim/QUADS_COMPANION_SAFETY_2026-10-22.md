# Татьяна: защита сундуков и базы (22 октября 2026)

## Инцидент
Пользователь тестирует Quads Companion 0.25.0: NPC взяла чужое снаряжение и киркой била в стену базы из каменного забора. Повреждение / prefab стены не диагностированы. В проекте SolidHitboxes v1.0.8 включён дружественный урон NPC, но это не доказанная причина работы киркой.

## Проверка реализации Quads
Источники: https://github.com/HardHeadHackerHead/valheim-mods/blob/main/mods/AICompanion/Armory.cs ; https://github.com/HardHeadHackerHead/valheim-mods/blob/main/mods/AICompanion/Work.cs ; https://github.com/HardHeadHackerHead/valheim-mods/blob/main/mods/AICompanion/Menu.cs ; https://github.com/HardHeadHackerHead/valheim-mods/blob/main/mods/AICompanion/Brain.cs

- Armory.Allowed читает NPC ZDO dhc_armory (default true): сама выбирает оружие, броню, инструменты из обычных доступных игроку сундуков дома, проверяя их примерно каждые 300 секунд, и может заменять имеющиеся вещи. **Выключить в меню Home → Ваши сундуки → «Берёт из ваших сундуков оружие, броню и инструменты получше и надевает их (старые кладёт обратно в сундук)»**. Отдельные приказы могут принудительно запустить обновление снаряжения. Не считать это глобальным CFG.
- В том же разделе Pantry / «Берёт еду из ваших сундуков» оставить OFF (default false). Stow / «Складывает добытое в ваши сундуки» разрешает только сдавать вещи, а не брать; можно OFF для полной изоляции. Дать NPC собственный отдельный пустой сундук. При появлении NPC способен сам занять свободную кровать и пустые сундуки.
- Work.AutoJobs при отсутствии отмеченных занятий выбирает Wood если есть топор и Stone + Ore если есть кирка. **Не оставлять все галочки занятий снятыми!** Для запрета добычи указать хотя бы одну явно разрешённую безопасную работу, например «Собирательство», а «Камень: валуны» / «Руда: залежи ...» / «Древесина» не отмечать. Приоритет домашних обязанностей отдельный: отключить «Mining» (сбор камня/руды) и временно «Build our plans» (строительство из BuildOrders за материалы сундуков, default enabled).
- Чтобы экстренно прекратить добычу, Orders → **«Стой здесь»**: Brain.Peaceful не вызывает Work.Tick при Order.Stay. **«Иди домой» означает самостоятельную работу, не простой.** Следование в режиме автоматического поведения тоже может помогать добывать рядом с игроком при добыче игрока.
- Забрать кирку и чужую экипировку во вкладке Gear; NPC также может сама скрафтить кирку при автономном развитии, поэтому одно изъятие без ограничения занятий ненадёжно.
- Work.Consider отбрасывает объект с Unity-компонентом Piece (постройки игрока). Если забор повреждался, возможно побочное попадание при добыче руды/камня рядом, либо специальная реализация забора не определяется как Piece / его коллайдер имеет другую иерархию. Проверить цель в её HUD, был ли забор действительно повреждён, и при возможности указать prefab.
- В текущем коде защитное расстояние от построек в 10 м используется для падающих стоящих деревьев, но нет доказанной универсальной настройки «не добывать рядом с базой».
- Модификация этих переключателей через обычные com.quad.aicompanion.cfg или .more.cfg невозможна: они персональные свойства NPC в ZDO мира, изменение только через интерфейс или отдельную доработку мода.

## Версии
По фактически открытой Thunderstore странице на 22.10.2026 опубликована **0.25.0**. В main GitHub есть исходники **0.25.1** с исправлением взаимодействия с StarLevelSystem: предотвращает копирование, модификаторы и звёзды у NPC. Это изменение НЕ обещает исправить выбор киркой стены. При публикации 0.25.1 обновлять мод синхронно у всех игроков с резервной копией мира; пока не считать его доступным на Thunderstore.

## Проверки и решение
Рекомендованный безопасный режим для Татьяны: Stay; Armory OFF; Pantry OFF; домашнее Mining OFF; Build our plans OFF; как минимум одно безопасное занятие при дальнейшей автономной работе, Stone/Ore OFF; изъять кирку. Дальше в тестовом мире проверить базу, сундуки, совместимость с EpicLoot / StarLevelSystem и боевое поведение. Реальные конфиги пользователь не менял в этой переписке: этот документ описывает действия внутри игры.
