# VSP Gamer — дополнительные универсальные слоты и рецепты (концепт, 22.10.2026)

## Исходный запрос

Сохранить работающий ExtraSlots и добавить в области справа от экипировки возле HipLantern **6 дополнительных ячеек**, желательно **универсальных** (любой тип предмета, без поштучного списка). Ориентир: Campsite Resources, любой щит, удочка, сеть, нож для забоя, пропашник. Пользователь показал область на скриншоте. Ничего не устанавливать/не менять в CFG до отдельного тестирования.

## ExtraSlotsCustomSlots

- Официальный пакет: https://thunderstore.io/c/valheim/p/shudnal/ExtraSlotsCustomSlots/ ; исходники: https://github.com/shudnal/ExtraSlotsCustomSlots
- **Работает вместе с ExtraSlots**, не вместо него; требует ExtraSlots и ConditionalConfigSync. Наш сборочный базис уже содержит оба. Нужно проверить конкретные версии зависимостей.
- Проверенный исходник `UserDefinedSlot.cs` v1.0.23: до **8** слотов `User defined - Custom slot 1..8`. Для каждого предусмотрены `Enabled`, `Name`, `Global keys`, `Item list`, `Item is visible`. `Item list` — разделённые запятыми **точные prefab имена или SharedData имена**.
- **Пустой список НЕ означает «любой предмет»**: `itemIsValid = item => ... itemList.Contains(item.m_shared.m_name) || itemList.Contains(item.m_dropPrefab.name)`. При пустом списке ничего не подходит, поддержка wildcard не обнаружена.
- Поэтому простая конфигурация без собственного патча может позволить один или несколько явно перечисленных предметов в слотах, но не все будущие предметы автоматически. Для настоящих «любых предметов» потребовалась бы отдельная доработка ExtraSlotsAPI и тестирование безопасного размещения/сохранения/перетаскивания.
- Примечание: пользовательские слоты ExtraSlotsCustomSlots — **слоты экипировки**, а не универсальное «второе хранилище». Не предполагать без теста, что предметы типа `Campsite Resources`, рыбацкой сети и инструментов можно свободно использовать или стакировать в этих ячейках.
- Все основные настройки ExtraSlotsCustomSlots синхронизируются от игрового хоста через ConditionalConfigSync по умолчанию. Опциональный отдельный пользовательский тест в мультиплеере должен иметь согласованные мод/конфиг у игроков, если они пользуются новыми слотами.
- В актуальном манифесте DLL **НЕ учитывать**: пользователь пока лишь рассматривает мод, не подтверждал установку.

### Проверка перед внедрением

1. Копия персонажа, скрин расположения слотов, BepInEx лог, версия ExtraSlots (текущая в Git CFG v1.2.21) и ExtraSlotsCustomSlots.
2. Убедиться в наличии свободного пространства UI при выбранном масштабе, совместно с HipLantern и Party HUD.
3. Для каждого типа (щит, удочка, сеть, нож, пропашник, ресурсы лагеря) узнать точный prefab из реальной игры, затем проверить попадание в слот, извлечение, активацию, сохранение при relog и работу стаков.
4. Не создавать универсальные «экипированные» стеки по непроверенному шаблону. Включать новые слоты постепенно, после резервного копирования персонажа.
5. Отдельно проверить EpicLoot/ExtraSlots и перенос предметов после смерти, особенно корректное восстановление из надгробия.

## Улучшение списка рецептов (Only Client)

Приоритет — решение, не меняющее рецепты/стоимости и не требующее установки у товарищей. Отобраны:

1. **Workstation Search 0.6.13**: https://thunderstore.io/c/valheim/p/ValheimEnthusiestKakimaki/Workstation_Search — поисковая строка, категории (включая `food`), опечатки, избранные рецепты. Only Client, без изменения крафт-правил; встраивается в стандартный InventoryGui. Рекомендован первым испытанием для VSP Gamer.
2. **CraftingSearch 1.0.2**: https://thunderstore.io/c/valheim/p/Ab5oluteZer0/CraftingSearch/ — поиск + сортировка Default, A–Z, Z–A, Type, Weight на верстаке, кузнице, котле и других станциях. Only Client. Проверен автором с Valheim 1.0.15, наш игровой клиент 1.0.20 — требует проверки. Альтернатива Workstation Search, не ставить оба без теста.
3. **CraftIndex 0.5.8**: https://thunderstore.io/c/valheim/p/jg224/CraftIndex/ — функции сортировки рецептов по биомам и питательности, но текущая страница Thunderstore содержит отметку **Deprecated**. К тому же изменяет меню молота, что потенциально пересекается с Quads Build Orders. Пока **не рекомендован**.
4. Старый **Goldenrevolver Sorted Menus 1.3.4** — обновлялся в 2024 г. и совместимость с 1.0.20 не подтверждена. Пока не внедрять.

Никакой из этих модов пока не выбран пользователем к установке, поэтому **плановое число DLL не изменено**. Не добавлять моды, меняющие одно и то же меню, без отдельного теста на копии персонажа.
