# MonsterLabzReid — концепт событий VSP Gamer

Статус: **исследование, не активирован**. Зафиксировано 22.10.2026.

## Идея

Использовать существ из `MonsterLabZ` для тематических рейдов `StarLevelSystem`. До внесения правок собрать проверенный каталог: внутренний prefab ID, биом, опасность/роль, ограничения по прогрессии, работоспособность в рейдах, потенциальная нагрузка на игровой хост из трёх игроков.

**Не добавлять существ в `RaidSettings.yaml` на основании только заголовков секций `MonsterLabZ.cfg`.** Сначала проверить, что prefab существует в фактически установленной версии DLL и является подходящим NPC. Не считать корабли, погодные эффекты и декоративных животных боевыми существами по умолчанию.

### Отправные данные

- `MonsterLabZ.cfg`: версия 3.0.15, **35 секций** (включая 2 корабля и 3 погодных эффекта; остальные 30 — существа, NPC и фауна, в том числе встречающиеся в ваниле).
- Нынешняя система рейдов: `StarLevelSystem`; отдельный рейд `pre_eikthyr_pack` проверен игроком, заканчивается после последнего убитого противника.
- Сохранять существующие 24 рейда без правки, пока не согласованы состав, условия и баланс новых рейдов.
- Избегать перегруза одновременно запущенного клиента и игрового хоста на `vsp-pc`.

## Настройки мира для будущих сражений с боссами

По пользовательскому скриншоту экрана World Modifiers, обсуждалось:

| Опция | Выбор на скриншоте |
|---|---|
| Бой | Очень сложно |
| Плата за смерть | Обычная игра |
| Количество ресурсов | ×0.5 |
| Частота набегов | Намного больше |
| Порталы | Без порталов с боссами |
| Бесплатное строительство | Выкл. |
| Набеги зависят от игрока (ванильный переключатель) | Выкл. |
| Огнеопасно | Вкл. |
| Пассивные враги | Выкл. |
| Без карты | Вкл. |

**Цель пользователя:** проходить боссов вместе с друзьями, получать все достижения. World Modifiers сами по себе не заменяют проверку работающего `AchievementEnabler` на игровом клиенте. В репозитории на эту дату конфигурация `MidnightsFX.AchievementEnabler.cfg` может отставать от локальной: пользователь ранее сообщал о правках `VanillaOnlyRequirements=true`, `ShowAllRequirements=true`, `ShowSecretAchievements=true`; точный актуальный локальный файл после изменений не загружен.

## Сопутствующие вопросы о существующем мире

- **OreMines:** если добавлен в уже созданный без него мир, разработчик рекомендует `Upgrade World` и `locations_add` для размещения новых шахт; это не требование пересоздать весь мир. Текущие значения: `Enable Mine Reset=On`, `Reset Day=30`, `Ore Veins Spawn Chance=35`. Сброс обновляет содержимое существующих шахт, а не добавляет отсутствующие локации.
- **EpicLoot:** `Defer Chest Loot Roll=true` — бросок дополнительной добычи при первом взаимодействии с новыми сундуками; ранее рассчитанные сундуки не пересчитываются. `Item Drop Limits=BossKillUnlocksNextBiomeItems` и `Global Drop Rate Modifier=0.3`.
- Перед использованием Upgrade World или других массовых инструментов сохранения мира **делать резервную копию `.db` и `.fwl`**; не выполнять команды экспериментально на основном мире. Для получения достижений избегать использования cheat/devcommands без понимания флагов.
- Источник OreMines: https://thunderstore.io/c/valheim/p/blacks7ar/OreMines/
- Источник EpicLoot: https://github.com/RandyKnapp/ValheimMods/blob/main/EpicLoot/src/Config/ELConfig.cs
