# VSP Sleep — Valheim (проект)

**Статус:** проектирование; код и DLL не созданы.  
**Назначение:** реализация сна по принципу S.T.A.L.K.E.R. — лечь в удобное время, выбрать длительность (варианты 2/4/6/8 часов) и согласовать перемотку с другими игроками.

## Обсуждаемый функционал

- Используется обычная ванильная кровать. Новые prefab не добавляем.
- Предлагаемое управление: `Shift+E` — меню выбора сна; время пробуждения видно до подтверждения.
- В P2P общее время меняет **только хост**; остальные игроки должны согласиться.
- Нельзя инициировать сон в бою или во время активного рейда; отказ или отключение игрока отменяет запрос.
- Взаимодействия с StarLevelSystem, EpicLoot, AICompanion и игровыми таймерами требуют проверки на отдельной копии мира.

Это **черновое ТЗ**, а не список подтверждённых возможностями Valheim функций. Сетевой API, механизм ускорения или скачка времени и ограничения ванильного сна предстоит изучить.

## План

1. Проверить API Valheim/BepInEx/Jotunn, обработку сна и времени в P2P.
2. Создать тестовый прототип сдвига времени на хосте.
3. Реализовать меню на обычной кровати.
4. Добавить голосование подключённых игроков и сетевую защиту.
5. Тестировать в TESTHEIM (бэкап .db/.fwl), после чего решать вопрос выпуска.
