# Valheim — VSP Gamer Modpack

> **Сложный, но управляемый Valheim:** более опасные противники и боссы, осмысленная прогрессия, редкая магическая добыча, дополнительные занятия, строительство и удобство повседневной игры. Настройки подобраны для совместного прохождения с сохранением ценности исследования мира и развития персонажа.

**Основа:** Valheim **1.0.20** (network 41) · Linux / Steam · **BepInEx**.  
**Состояние документации:** 23 октября 2026 года.  
**Текущее решение (23.10.2026):** в обязательный `Server / Client`-комплект **выбран [DoorDirector 0.3.0](https://thunderstore.io/c/valheim/p/TomTomDK/DoorDirector/)** для автоматического закрытия дверей и ворот, оставляемых открытыми Quads Companion. **Плановый состав: 45 S/C + 10 C = 55 активных DLL.** На игровом ПК новая DLL ещё не проверена. Последний **проверенный на диске комплект остаётся прежним: 44 S/C + 10 C = 54 DLL** (побайтово сверено 22.10). [Настройка DoorDirector](config/com.tomtom.doordirector.cfg) — подготовленный baseline, не снятый с ПК. ExtraSlotsCustomSlots отменён, существующий ExtraSlots сохранён.  
**Отдельная правка SLS (23.10.2026):** [отключена географическая/зональная звёздность, приближен к ванильному баланс 0–2★, 3★ сделаны редкостью, отключён дистанционный бонус добычи](STAR_LEVEL_SYSTEM_BALANCE_2026-10-23.md). Новые значения **записаны только в Git**, игровая проверка не проведена.  
**Развёртывание:** **45 Server / Client по новому плану**, **10 Only Client**, **0 Only Server**; **из них DoorDirector — 1 выбранная, ещё не проверенная на диске DLL**, остальные 54 DLL проверены при локальном разделении 22.10.2026. Dedicated server не используется: хост — клиент одного из игроков. Производитель DoorDirector требует установки у хоста и всех подключающихся игроков с одинаковой версией. Проверка работы с Quads Companion и игровым Valheim 1.0.20 — впереди.  
**Учёт инвентаря:** первоначально 48 записей DLL (21.10), `DigDug.dll*` исключён; после замен/добавлений локально проверены **54 активные DLL** (22.10). DoorDirector добавляет **одну новую обязательную DLL**: **55 активных по плану / 56 с отключённым DigDug**. BlindCartographer заменяет NoMapCartographyTable **1:1**, Venture Logout Tweaks заменяет KeepCharacterEffects, WorkbenchesPlus входит в 10 клиентских. Не путать новый план с проверенным архивом.  

Это **каталог состава и настроек**, а не архив готовых DLL и не список проверенных совместимых версий. Названия DLL взяты из пользовательского инвентаря; ссылки ведут на **страницы загрузки** (не фиксированные версии). Под «Server / Client» понимается **обязательность по политике сборки**, а не обещание автора мода о поддержке headless dedicated server. Это ещё проверяется по логам и игровым тестам.

## Ключевые особенности сборки

- **Hardcore и прогрессия:** StarLevelSystem, MonsterLabZ и BossGate повышают сложность и связывают доступ к части возможностей с победами над боссами. `Custom Raids` удалён из активного состава.
- **Добыча и награды:** EpicLoot использует профиль `Legendary` с намеренно редкими магическими предметами; OreMines добавляет шахты; есть рыбная ловля и новые лагерные объекты.
- **Строительство, быт и оборона:** подвалы, усиленные колья, расширенные зоны станций, крафт из сундуков, автозаправка плавилен и упорядоченное хранение. Добавлен **DoorDirector** (плановая установка) для автозакрытия дверей и ворот после прохода компаньона, без автоматического открытия для врагов.
- **Приручённые существа:** индивидуальная защита с восстановлением через 180 секунд; прочие настройки подробно записаны в [handoff](HANDOFF_2026-10-21.yaml).
- **Необязательный клиентский комфорт:** фермерская сетка, чертежи построек, компас, уведомления о добыче, вид от первого лица, автощит и редактор настроек.

**Источники состояния:** [архив конфигов 22.10.2026](LOCAL_SNAPSHOT_AUDIT_2026-10-22.md), [сведение Git-патчей](CONFIG_RECONCILIATION_2026-10-22.md) и **локальная проверка комплекта 54 DLL пользователем 22.10.2026**. Наличие CFG или DLL подтверждает файл на диске, но не безошибочную работу конкретного мода. Git **не синхронизируется автоматически** с игровым ПК. Текущий baseline StarLevelSystem от 23.10.2026 основан на сообщённой проблеме с чрезмерной звёздностью; локальное применение и проверка отложены до теста в игре.
