# Valheim Dedicated Server

**Статус:** подготовлена проектная папка. Концепт выделенного сервера ещё не утверждён.

## Назначение
Отдельное пространство для проектирования, развёртывания и сопровождения Valheim Dedicated Server в рамках VSP Gamer.

## Границы
- Этот проект — **dedicated server**, не P2P-мод VSP Sleep.
- Платформа, хост, ресурсы, сетевая схема, версия сервера, резервное копирование и набор модов: **[Needs confirmation]**.
- Фактическое развёртывание, изменение конфигураций, доступов, firewall, игровых миров и DNS — только после согласования.

## Порядок работы
1. Зафиксировать концепт и требования (количество игроков, моды, доступность, целевая инфраструктура).
2. Собрать проверенное текущее состояние без модификаций.
3. Подготовить архитектуру, risk register, backup/restore и rollback.
4. Составить поэтапный план внедрения с проверками и критериями приёмки.
5. Только после отдельного одобрения выполнять изменения.
