# KeepCharacterEffects — заменён лучшим доступным решением

- **Дата решения:** 22 октября 2026.
- **Старый кандидат:** [KeepCharacterEffects, Virkatta (Nexus 4410)](https://www.nexusmods.com/valheim/mods/4410), Only Client.
- **Причина отказа:** пользователю не удаётся скачать мод с Nexus даже через FullVPN. Практическая доступность низкая; загрузка на ПК не подтверждалась.
- **Выбранная замена:** [Venture Logout Tweaks, VentureValheim v1.0.0](https://thunderstore.io/c/valheim/p/VentureValheim/Venture_Logout_Tweaks/), Only Client. Доступен на Thunderstore. Восстанавливает документированный набор ванильных эффектов: Rested, Wet, poison, burning/spirit, frost, lightning, vanilla potions, boss powers, death effects и др.
- **Ограничение:** не восстанавливает автоматически произвольные дополнительные эффекты модов. Последняя версия опубликована под Valheim 1.0.7, а целевая сборка VSP Gamer — 1.0.20: необходим локальный тест совместимости с ForsakenPowersPlusRemastered.
- **Состояние:** пользователь выбрал Venture Logout Tweaks для сборки, но фактическая установка DLL и успешный запуск пока не подтверждены. Не ставить одновременно с KeepCharacterEffects. У Venture Logout Tweaks нет штатного CFG, поэтому новый конфиг не создавать.
- **Учёт DLL:** замена 1:1 в необязательном клиентском наборе; число плановых активных модов не изменилось: 44 S/C + 9 Only Client = 53 (после установки всех выбранных).
